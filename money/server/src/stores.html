Stores

Where receipts come from. What you enter here stays on this server, in a file only it can read. It is never part of the budget, so it doesn't sync to any device.

Amazon

The server signs in with amazon-orders at each sync and reads the last 30 days of orders.

The secret is the key shown when you add an authenticator app on Amazon (Login & security → 2-Step Verification). It lets the server make its own one-time codes. A code texted to your phone can't be used here.

Costco

Costco is read with your own signed-in costco.com page, so your Costco password never leaves Costco. A bookmarklet asks Costco for the last year of warehouse and gas receipts and sends them here, using a key that can only upload receipts.

  1. Drag the button above to your bookmarks bar.
  2. Open costco.com, sign in, and go to Orders & Purchases.
  3. Click the bookmark. It tells you how many receipts it sent.
