# The demo's person

`alex.jpg` is the picture `alex` wears: the user the demos
(`nix run .#<app>-demo`) and the app screenshots (`.github/screens/apps.md`)
sign in as under dev auth, through `ARK_DEV_PICTURE`, which a dev server's
own user (`ARK_DEV_USER`) is given and `/auth/picture` serves from the file.

It is a 512-pixel square cut from "Gray-haired man portrait (Unsplash).jpg"
on Wikimedia Commons,
https://commons.wikimedia.org/wiki/File:Gray-haired_man_portrait_(Unsplash).jpg
— photographed by Foto Sushi (https://unsplash.com/@fotosushi) in California
on 25 August 2016, from https://unsplash.com/photos/6anudmpILw4, and released
under CC0 1.0 (public domain), Unsplash's licence before 5 June 2017: no
permission or credit needed. The man in it is not named, and nothing here
says he is anyone; "alex" is the demo's name, not his.
